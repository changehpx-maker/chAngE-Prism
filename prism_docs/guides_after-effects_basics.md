## Basics

The Basics section gives an overview of the [Prism-After Effects](https://prism-pipeline.com/docs/latest/plugins/after-effects/) integration. This includes how to access Prism in After Effects, how to open and save scene files, how to import media, how to check for new media versions and how to render a composition.
