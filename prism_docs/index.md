## Overview

**Prism is a pipeline software for organizing and automating workflows of animation and VFX projects.**

It is a very artist friendly tool, easy to setup and intuitive to use. No programming skills are required to setup and to use Prism, which make it the perfect tools for teams and individuals, who want to focus on the creative aspects of a project.

## Getting Started

For new Prism users we recommend to go through the [Getting Started](https://prism-pipeline.com/docs/latest/getting_started/#getting-started) guides to get familar with the basic features and functionality of the pipeline.
