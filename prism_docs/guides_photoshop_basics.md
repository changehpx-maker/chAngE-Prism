## Basics

The Basics section gives an overview of the [Prism-Photoshop](https://prism-pipeline.com/docs/latest/plugins/photoshop/) integration. This includes how to setup Prism in Photoshop, how to access Prism in Photoshop, how to open and save scene files, how to import media and how to export media.
