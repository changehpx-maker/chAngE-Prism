## Plugins

The features of Prism can be extended using plugins to tailor it to the needs of specific projects and studios.

Plugins can integrate Prism into new DCCs or add features to Prism in existing DCCs.

There are different categories of plugins like free/open source plugins, Prism Plus plugins, plugins developed by a 3rd party developer, which are shared with the community and plugins developed inhouse by studios to customize Prism to their individual needs.

## 3rd party plugins

The following Prism plugins were developed and shared by 3rd party developers. For questions and support about these plugins, please get in touch with the developers directly.

[SynthEyes](https://github.com/AltaArts/SynthEyes_Integration--Prism-Plugin)

Integreates Prism with SynthEyes.

Developed by Joshua Breckeen (AltaArts).

[Slack](https://fraktlfx.com/plugins/prism-slack/)

Developed by Fraktl.

Developed by Joshua Breckeen (AltaArts).

[SendToClient](https://github.com/EFV0804/PrismPlugin_SendToClient)

Add an option to copy media versions into a client delivery folder.

Adds the ability to save a shortcut to a project located in Davinci Resolve's internal database.
