## Photoshop

This plugin integrates Prism into [Adobe Photoshop](https://www.adobe.com/products/photoshop.html).

The plugin has been tested with Photoshop 2023-2026. The currently recommended version that integrates best with Prism is Photoshop 2026.

## Guides

This guides section covers the Prism-Photoshop integration.

![[Thumbnail: Photoshop - Basics]](https://prism-pipeline.com/docs/latest/_images/Photoshop_Basics_thumbnail.jpg) [Basics](https://prism-pipeline.com/docs/latest/guides/photoshop/basics/)

## Setup

The Photoshop plugin can be installed via the Prism Hub.

Once the plugin has been installed, the Prism-Photoshop UXP plugin needs to be installed as well:

`Prism User Settings > DCCs apps > Photoshop > Install UXP Plugin.`

## Accessing Prism in Photoshop

`Plugins > Prism Pipeline > Prism Pipeline.`

The appearing "Prism Menu" window is dockable (2) anywhere in Photoshop.

![[Photoshop - Access]](https://prism-pipeline.com/docs/latest/_static/plugins/photoshop/Photoshop_Access.png)
- save and version up your scene
- save, version up your scene and add a description/thumbnail
- export images
- open the Project Browser
- open the Prism Settings

## Saving Scenefiles

New scenefile versions can be saved via the Prism Menu or by opening the Project Browser and selecting "Create new version from current" from the context menu in the "Scenefiles" tab.

![[Photoshop - Scenefiles]](https://prism-pipeline.com/docs/latest/_static/plugins/photoshop/Photoshop_Scenefiles.png)

## Importing Images

To import an image from the Prism project into Photoshop, navigate to a media version in the Project Browser. Right-click on the image and select "Import images...", or simply drag and drop the image into Photoshop.

![[Photoshop - Import]](https://prism-pipeline.com/docs/latest/_static/plugins/photoshop/Photoshop_Import.png)

## Exporting Images

To export an image from Photoshop to the Prism project, select "Export" from the Prism menu. The exported image can then be found in the "Media" tab of the Project Browser.

![[Photoshop - Export]](https://prism-pipeline.com/docs/latest/_static/plugins/photoshop/Photoshop_Export.png)
