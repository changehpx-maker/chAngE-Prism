## Getting Started

These guides will help you with your very first steps in Prism.

They are designed to get you up and running in no time.

No prior knowledge of Prism is required.

For further information about specific Prism Core features see the [General](https://prism-pipeline.com/docs/latest/general/#general) section.

For further details about specific DCC integrations see the [Plugins](https://prism-pipeline.com/docs/latest/plugins/#plugins) section.
