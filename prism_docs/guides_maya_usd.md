## USD

The USD section covers the Maya-USD workflow in Prism. This includes Modeling, Surfacing, Rigging, Layout, Animation and Lighting. All guides are using the "Sunrise" exsample project, which can be downloaded below, to demonstrate the workflow.

> [!note] Note
> After the download has been completed, follow the instructions in the "README\_Sunrise" text file inside "Prism-Pipeline\_Sunrise\_ProjectFiles.zip" for proper use of the project (to preserve relative paths).
